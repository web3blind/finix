Finix: ключ восстановления / Recovery key

Работает локально без сети. Приватный ключ не показывается и не отправляется на сервер. Works offline. The private key is never displayed or uploaded.

Потеря ключа = потеря доступа к резервным копиям. Losing the key means losing access to backups. Сохраните файл в надёжном месте, отдельно от резервных копий. Файл не защищён паролем. Store the file safely, separate from backups. The file is not password protected.

Создайте ключ. / Generate a key.

Проверка только сравнивает локально сохранённый ключ с текущим. Здесь нет регистрации или подключения профиля. Verification only compares the saved key locally with the current key. No profile is registered or connected.
